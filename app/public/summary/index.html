光路·歌词

把听歌，变成在歌里走路。

网易云端搜歌 / 扫码登录后播放歌曲，画面里一个发光小人沿 low-poly 道路前行，路边景物随音乐律动，歌词按真实时间轴逐句高亮同步。

音乐可视化Low-poly 3DLRC 逐句同步全栈应用

技术形态

从纯静态站，到全栈动态应用

前端

  • React 19
  • Vite
  • TypeScript
  • Three.js
  • Tailwind
  • shadcn/ui

渲染 3D 光路场景、频谱驱动的律动特效与逐句高亮的歌词界面。

后端

  • tRPC
  • Hono
  • Drizzle
  • MySQL

承载网易云扫码登录、搜索歌单与流式音频代理，cookie 只存服务端。

核心组成

三大块，撑起一条会唱歌的路

01

3D 场景 · low-poly

  • 发光小人沿道路持续前行
  • 三季节主题：春日清晨 / 秋日夕阳 / 冬夜隆冬
  • Bloom 泛光营造暖光氛围
  • 树冠呼吸、粒子、路灯光晕随音乐脉动
02

音频与歌词

  • Web Audio 频谱分析驱动场景律动
  • 官方 LRC 时间轴精确逐句同步
  • 当前行高亮发光、滚动跟随、点击跳转
  • 本地音乐 + LRC 备用通道 · 纯音乐提示
03

网易云接入

  • 扫码登录，cookie 只存服务端
  • 云端搜索 / 歌单浏览
  • VIP 歌曲标注并禁播
  • 后端流式音频代理，透传 Range，保证频谱分析可用
